# WEEK 1 PYTHON DATA ANALYSIS REPORT

## Introduction

The Week 1 practical session focused on learning the basic concepts of Python programming and how they can be applied to simple data analysis tasks. The activities covered variables, data types, type conversion, strings, lists, dictionaries, and working with structured student data. The practical exercises were carried out using information from 20 AUCA students, including their academic and personal data.

The personal profile used for the exercises was: my_name = "Docile Uwizeye", my_age = 23, my_gpa = 3.2, and am_i_present = True.

## Objectives

The practical work was designed to help me:

* Understand and work with different Python data types.
* Perform type conversion and manipulate strings.
* Create, access, update, and work with lists and dictionaries.
* Retrieve specific information from structured student data.
* Calculate basic statistics, including the average, highest, and lowest scores.
* Find students with the highest and lowest scores without using loops.

## Activities and Implementation

The practical started with the creation of variables containing information such as a student's name, age, GPA, and attendance status. The `type()` function was used to determine the data type of each variable. I also practiced type conversion by changing a numerical value stored as a string into an integer and then using it in mathematical calculations.

The session also covered string manipulation. Different string operations and methods, including `.upper()`, `len()`, and slicing, were used to modify and retrieve parts of text. Lists were then used to store student scores, allowing individual elements to be accessed, added, and updated. Basic statistical calculations were performed to determine the average, highest, and lowest scores.

Dictionaries were introduced for organizing related information through key-value pairs. A dataset containing 20 student records was created using a list of dictionaries. Using list comprehensions, different details such as student names, scores, districts, academic programs, and attendance were extracted from the dataset.

Further analysis was performed to obtain important statistics from the student dataset. There were **20 students** in total. Their average score was **76.5**, while the highest score was **94** and the lowest score was **55**. The distribution of students by district was also examined. Gasabo had **5 students**, Kicukiro had **4 students**, and Musanze had **2 students**.

The final activity involved identifying the students with the highest and lowest scores without using loops. The `max()` and `min()` functions were used together with `.index()` to locate the positions of the highest and lowest scores. These positions were then used to obtain the relevant student names and attendance details.

The student with the highest score was **Sandrine Umutoni**, who achieved **94%** and had an attendance rate of **97%**. The student with the lowest score was **David Hakizimana**, who scored **55%** and had an attendance rate of **72%**.
