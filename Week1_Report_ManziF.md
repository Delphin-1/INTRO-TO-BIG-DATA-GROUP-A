This week's lab was about getting comfortable with Python basics and using them to do some simple data analysis. We started from the very beginning — creating variables, working with different data types like strings, integers, floats and booleans, and printing them out with their types. After that we worked with strings — formatting sentences using f-strings, converting text to uppercase, checking the length of a string, and slicing parts of it. These feel like small things but they come up a lot when you are cleaning data.

The list section was where things started to feel more like actual data analysis. We had a list of quiz scores and had to find the first and last values, count them, calculate the average, and get the highest and lowest. The last part was the most interesting. We also looked at individual records and counted how many students came from different districts. Finding the top and bottom student without using any loop was a good challenge that made me think more carefully about how Python's built-in functions work together.

Overall the lab showed me that even with basic Python you can already start answering real questions about a dataset.
