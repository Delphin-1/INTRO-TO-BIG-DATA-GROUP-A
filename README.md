# Python Basics Lab 1

This project is a short Jupyter Notebook practice on beginner Python concepts. It demonstrates variables and data types, type conversion, string operations, and list handling using simple examples.

Open `29275_Mukunzi_Eduine_lab1.ipynb` in Jupyter Notebook or VS Code to explore the exercises and run the code cells. The notebook is designed to help reinforce basic Python syntax and common data manipulation techniques.
